# Administrative Boundaries

Folder ini digunakan untuk menyimpan data batas administrasi desa dan kelurahan di Provinsi Lampung.

## Data Source
- Provider: Badan Informasi Geospasial (BIG)
- Service: BATAS_DESAKEL_AR
- Format target: GeoJSON
- Coordinate System: EPSG:4326

## Directory
- `raw/` : Data asli hasil unduhan BIG.
- `processed/` : Data yang telah dibersihkan dan divalidasi.

## Data Policy
Data harus mencantumkan sumber, tanggal pengambilan, dan informasi lisensi.
Data asli tidak boleh diubah.
